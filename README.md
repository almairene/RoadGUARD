# RoadGuard – Intelligent Pothole Detection and Road Safety Network

## About the Project
RoadGuard is an intelligent road-safety system designed to detect potholes, track hazardous road conditions and alert nearby vehicles. It aims to improve road safety through real-time reporting, location tracking and centralized monitoring.

## Key Features
- **Live Dashboard:** Displays pothole reports, severity and repair status.
- **Road Analytics:** Shows KPI comparisons and interactive daily, weekly and monthly report trends.
- **Interactive Map:** Uses Leaflet, OpenStreetMap and marker clustering, with severity, status, date and location filters.
- **Vehicle-to-Vehicle Alerts:** Notifies nearby vehicles about road hazards.
- **Fleet Simulation:** Provides simulated vehicle profiles, detection histories, and start, pause and reset controls.
- **GPS Tracking:** Records the approximate location of reported hazards.
- **Weather Monitoring:** Displays rainfall and weather information.
- **Risk Analytics:** Prioritizes hazardous road locations.
- **Authority Portal:** Supports report verification, rejection, repair assignment, progress, notes and history.

## Technologies Used

## Prototype Implementation
The prototype uses clearly labeled sample reports and simulated vehicle data. Reports, authority updates, vehicle positions, alerts and preferences are stored in the browser's local storage and shared across the dashboard modules. Real smartphone sensor integration and hardware-based detection can be explored in future development.

## Future Scope
- ESP32-based pothole detection.
- MPU6050 vibration sensing.
- GPS module integration.
- Cloud-based real-time reporting.
- Hardware-based vehicle-to-vehicle communication.

## Project Goal
To create safer roads through intelligent hazard detection, timely alerts and efficient road maintenance monitoring.
